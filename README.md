# Сверка ExpertOnline

Сравнивает «Получено от плательщиков» на страницах групп HolliHop (expertonline.t8s.ru) со сводкой в таблице учеников и сохраняет отчёт `.docx` с расхождениями.

## Как пользоваться

1. Открыть **Sverka** (`Sverka.exe` на Windows, `Sverka.app` на macOS).
2. Выбрать таблицу `.xlsx` и PDF «Курсы для сведения» (в нём ссылки на группы).
3. Нажать **Сверить** — откроется окно с обычной страницей входа сайта. Войти в нём своим логином и паролем.
4. Дальше программа сама читает страницы групп, закрывает окно сайта и сохраняет `Расхождения <дата>.docx` рядом с таблицей.

Пароль программа не спрашивает и не хранит: вход делает человек на странице сайта. Потом программа только читает страницы групп из PDF (GET) — ничего на сайте не меняет. Ссылки PDF не на https://expertonline.t8s.ru пропускаются.

## Ежедневный отчет

Кнопка **«Отчет»** и даты «с — по» (одна дата или диапазон; нужна только таблица xlsx). Программа пишет `Отчет ДД.ММ.ГГГГ–ДД.ММ.ГГГГ.docx` рядом с таблицей — каждый день на отдельной странице, текст строка в строку как ручной отчет руководителю («Всего обработано» остаётся пустым).

| Строка отчета | Откуда |
|---|---|
| Получено оплат, Сумма оплат за сегодня | журнал продаж справа на листе `ЗП 26-27`, строки с этой датой |
| Процент выполнения плана | продажи с начала месяца по эту дату от плана месяца (строка «Итого» блока месяца слева на `ЗП 26-27`); половина округляется вверх |
| Годовой курс, В деньгах, тарифы | сводка наверху листа `<ПРЕДМЕТ> ГК` — те же формулы COUNTA / SUM / COUNTIF, но по строкам с датой не позже дня отчета. Красные/серые строки (возвраты, ушедшие) стоят выше этих диапазонов; СВУ МВД — отдельная когорта, по дате не фильтруется |
| Стартер-пак | число строк «Стартер-пак» на листе `<ПРЕДМЕТ> спецкурсы` по эту дату; строки нет, если предмет его не продаёт |

Правила подобраны так, что отчет за 1 октября совпадает с ручным байт в байт. Если журнал продаж заполнен не до конца диапазона, программа предупредит — у более поздних дней оплаты будут нулевыми.

## Обновления

Каждая сборка из `main` публикуется как релиз `build-N` (в заголовке окна — номер текущей сборки). При запуске программа проверяет последний релиз; если он новее, вверху окна появляется «Доступна новая версия»:

- **Windows** — кнопка «Обновить»: программа скачивает новый `Sverka.exe`, сверяет размер и SHA-256, закрывается, подменяет файл и запускается уже новой версией.
- **macOS** — кнопка «Скачать» открывает страницу релиза; `Sverka.app` заменить вручную.

Без интернета проверка просто пропускается. Сборки до появления обновлений (без номера в заголовке) нужно один раз скачать вручную со страницы Releases.

## Что с чем сравнивается

| Группа на сайте | Значение в xlsx |
|---|---|
| `26/27 октябрь ГК ОБЩ ПРОФИ 2` | лист `ОБЩ ГК`, сводка наверху: колонка «Октябрь» (второй блок месяцев), строка под подписью `ГК профи 2` |
| `26/27 СВУ МВД ОБЩ` (без месяца) | сумма строки `СВУ МВД` по всем месяцам |
| `25/26 на пересдачу / обществознание` | лист `ОБЩ спецкурсы`, строка «Количество … На пересдачу» |
| несколько групп → одна ячейка (две «на пересдачу: математика») | сравнивается сумма групп |
| `С-П` | `Стартер-пак` во всех листах «спецкурсы» |

По каждой группе программа дополнительно открывает её список «Оплаты» на сайте (все страницы; только читает, кнопки «изменить»/«удалить» не трогает) и сверяет по ученикам: плательщики «Фамилия И. О.» на сайте ↔ ученики, которых складывает формула SUMIF ячейки xlsx. Так находятся и группы, где сумма сходится, но ошибки двух учеников гасят друг друга (статус «РАСХОЖДЕНИЕ по ученикам»).
- В таблице «Расхождения» колонка «Ученики с расхождением» — кто и на сколько.
- Раздел «Расхождения по ученикам» — подробно, с «Где ещё в xlsx»: другие строки таблицы с тем же учеником (частая причина: записан не в ту группу или лист).
- «Возможные опечатки в ФИО» — на сайте и в xlsx одна сумма, а фамилия отличается на букву; это не денежное расхождение.

Статусы в отчёте: **совпадает**, **РАСХОЖДЕНИЕ** (суммы не равны или на сайте деньги, а в xlsx нет строки), «нет в xlsx, на сайте 0», «неоднозначно» (подходит несколько листов одного предмета), «ошибка загрузки».

## Разработка

```bash
pip install -r requirements.txt
python test_sverka.py                    # самопроверка на синтетических данных и локальном фейковом сайте
python test_sverka.py --frozen <Sverka>  # то же для собранного приложения: окно сайта, вход, чтение страниц
python test_sverka.py --swap             # Windows: подмена запущенного .exe при обновлении
python sverka.py                         # окно
python sverka.py --xlsx t.xlsx --pdf c.pdf   # консоль (окно сайта для входа всё равно откроется)
python sverka.py --xlsx t.xlsx --report-from 2026-10-01 --report-to 2026-10-15   # отчет в консоли
```

Сборка: `pyinstaller --windowed --name Sverka sverka.py` (macOS, `.app`) и `pyinstaller --onefile --windowed --name Sverka sverka.py` (Windows, `.exe`). PyInstaller не собирает под чужую ОС, поэтому `.exe` и `.app` собирает GitHub Actions (`.github/workflows/build.yml`): после зелёных проверок на `main` он публикует релиз `build-N`.

Окно сайта на Windows работает через Microsoft Edge WebView2 (есть в Windows 10/11).

Неподписанное приложение: на macOS первый запуск — правый клик → «Открыть»; на Windows SmartScreen — «Подробнее» → «Выполнить в любом случае».
